RateMyMustang is a website that is similar to RateMyProfessors

The purpose of this website is to display information about certain teachers in a way that is accurate to the general student population's agreement of facts and perception of an instructor.

This is meant to encourage a more democratic style of thinking, and creates a more collaborative environment in which students can accurately search information, and contribute to this project.


This is property of a Abraham Lincoln High School student. 

Although it is impossible to choose teachers---and to an extend---courses as well, it is possible to aptly prepare for an otherwise disastrous educational experience from a faculty member through this website. This is what we hope to achieve.
